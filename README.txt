Toddler Coloring Book (installable app)

1. Put all files in this folder on any HTTPS host (Netlify Drop, GitHub Pages, Cloudflare Pages).
2. Open the site once on the phone or tablet.
   iPhone/iPad (Safari): Share > Add to Home Screen.
   Android (Chrome): menu > Install app (or Add to Home screen).
3. Launch it from the home-screen icon. It opens full screen with no address bar and works offline.

To keep a child inside the app:
   iPhone/iPad: Settings > Accessibility > Guided Access, then triple-click the side button inside the app.
   Android: Settings > Security > App pinning, then pin the app from Recents.
